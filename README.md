# ☕ Lista de Exercícios: Concatenação e Operadores Aritméticos em Java

Repositório criado para armazenar a resolução de exercícios práticos em **Java**, focados no uso de **concatenação de strings** e **operadores aritméticos**, desenvolvidos durante os estudos de Java FullStack.

---

## 📋 Sobre os Exercícios

O projeto aborda conceitos fundamentais da linguagem Java através de exemplos práticos divididos em duas categorias principais:

### 🔤 Concatenação
1. **Apresentação Pessoal:** Exibição de nome, cidade e idade em uma única frase formatada.
2. **Carrinho de Compras:** Cálculo dinâmico do valor total de um produto com base na quantidade e preço unitário.
3. **Soma Formatada:** Exibição de operações matemáticas inseridas diretamente em um texto concatenado.

### ➕ Operadores Aritméticos
- **Comportamento de Precedência e Concatenação:** Análise do comportamento do operador `+` ao misturar strings com números (com e sem uso de parênteses).
- **Operações com Inteiros (`int`):** Soma, subtração, multiplicação, divisão e resto (`%`) entre dois números inteiros.
- **Operações com Decimais (`double`):** Cálculos aritméticos utilizando números com ponto flutuante.
- **Média Escolar:** Cálculo da soma e média aritmética de três notas.
- **Precedência de Operadores:** Aplicação correta de expressões matemáticas com e sem uso de parênteses (`a + b * c` vs `(a + b) * c`).
- **🚀 Desafio (Conversor de Tempo):** Conversão de segundos totais (3785s) em minutos inteiros e segundos restantes utilizando divisão e o operador módulo (`%`).
